# 카테고리 키워드 소싱판별 마법사 1.0

셀러라이프에서 내려받은 카테고리별 키워드 엑셀을 필터링하고, 한이룸 소싱판결사로 판별 결과를 확인하는 프로그램입니다.

## 실행 방법

1. [Node.js 18 이상](https://nodejs.org/)을 설치합니다.
2. GitHub의 **Releases**에서 최신 ZIP 파일을 내려받아 압축을 풉니다.
3. 압축을 푼 폴더에서 `실행하기.bat`를 더블클릭합니다. 처음 실행할 때 필요한 라이브러리가 자동으로 설치됩니다.
4. 브라우저가 열리면 관리자에게 받은 인증코드를 입력합니다.

## 공개 저장소 사용 시 주의

- 이 저장소에는 사용자 엑셀 파일, 로그인 정보, 메일 앱 비밀번호, 브라우저 인증 상태를 올리지 않습니다.
- `auth-store.json`, `.env`, `*.xlsx`, `node_modules`는 GitHub 공유 대상에서 제외됩니다.
- 화면에 표시되는 파일 업로드 비밀번호는 공개 저장소에서 보안 장치가 될 수 없습니다. 외부에 공개한 서비스에서 중요한 파일을 보호해야 한다면 서버 측 사용자 인증을 별도로 구현해야 합니다.

## 사용 순서

1. 카테고리 엑셀파일을 올립니다.
2. 필요하면 원본 엑셀 필터 조건을 설정한 뒤 **전체 키워드 추출**을 누릅니다.
3. 추출된 대상 수가 최대 조회 건수에 자동 입력됩니다.
4. **소싱판별 실행**을 누르고, 결과를 엑셀로 내려받습니다.

판별 데이터는 `https://select.irumai.kr/`의 응답을 사용합니다.

## 윙렌즈 통합 사용

`wing-lens-extension` 폴더는 이 프로그램과 함께 쓰는 Chrome 확장프로그램입니다. `http://localhost:8787`의 아래쪽 **쿠팡 판매지표 분석** 영역에서 검색어를 입력하면, 설치된 확장프로그램이 쿠팡 검색·쿠팡윙 지표 조회를 처리하고 결과를 같은 페이지에 표시합니다.

1. `실행하기.bat`를 실행해 `http://localhost:8787`이 열리는지 확인합니다.
2. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `sourcing-judge-admin/wing-lens-extension` 폴더를 선택합니다.
4. 확장프로그램의 **시크릿 모드에서 허용**을 켜고, 확장프로그램에서 쿠팡윙 로그인을 진행합니다.
5. 확장프로그램을 새로고침합니다. 이후 `http://localhost:8787` 페이지를 새로고침하면, 아래쪽 **쿠팡 판매지표 분석**에서 바로 조회할 수 있습니다.

윙렌즈에서 **분석 시작**을 누르면 입력한 키워드와 페이지의 일반 쿠팡 검색 탭을 한 번 자동으로 열어 결과를 읽습니다. 접근 제한을 피하기 위해 자동 반복 요청이나 차단 우회는 하지 않습니다. 쿠팡윙 로그인 정보와 쿠키는 브라우저 밖으로 전송하거나 저장하지 않습니다.

### 판매자 계정 전환 안내

윙렌즈의 **판매자 계정 관리**에서는 계정의 구분용 별칭만 최대 5개까지 저장할 수 있습니다. 조회 중 쿠팡윙 세션이 끊기면 다음 별칭을 선택해 시크릿 로그인 창을 열어 안내합니다. 비밀번호, 쿠키, 인증정보는 저장하지 않으며 실제 로그인은 사용자가 직접 진행합니다.
