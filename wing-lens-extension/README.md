# 윙렌즈 로컬

로그인된 쿠팡윙 탭을 이용해 쿠팡 검색 상품의 배송방법, 가격, 리뷰수, 클릭수, 월 판매량, 월 매출과 전환율을 확인하는 로컬 크롬 확장 프로그램입니다.

## 설치

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. 이 `wing_lens_local_original` 폴더를 선택합니다.

## 사용

1. `wing.coupang.com`에 로그인한 탭을 하나 열어 둡니다.
2. 크롬 도구 모음에서 `윙렌즈 로컬` 아이콘을 누릅니다.
3. 검색어와 분석할 상품 수를 선택한 뒤 `분석 시작`을 누릅니다.
4. 쿠팡 검색 결과를 불러오기 위한 비활성 탭은 자동으로 열렸다 닫힙니다.
5. 일반 쿠팡 검색 페이지에서는 오른쪽 아래 `지표 표시 시작` 버튼으로 상품 카드 위에 지표를 붙일 수 있습니다.

배송방법은 각 상품 상세페이지의 `배송/교환/반품 안내` 탭에서 읽으며 다음과 같이 표시합니다.

- 업체직송 → 국내
- 설치배송 → 설치
- 순차배송 → 로켓
- 해외직구 → 해외

## 계산식

- 전환율: `판매 28일 ÷ PV 28일 × 100`
- 매출 추정: `판매 28일 × 판매가`

매출은 실제 정산 매출이 아니라 현재 확인된 판매가를 이용한 단순 추정값입니다.

## 개인정보와 세션

- 조회는 설치된 브라우저 안에서 실행됩니다.
- 별도의 개발자 서버로 쿠키, 검색어 또는 결과를 전송하는 코드는 포함하지 않습니다.
- 쿠팡윙 세션이 만료되거나 API 구조가 변경되면 조회가 실패할 수 있습니다.

## 이름 변경

개인 또는 사업용 이름으로 바꾸려면 `manifest.json`의 `name`, `description`과 `dashboard.html`의 화면 제목을 수정하면 됩니다.
