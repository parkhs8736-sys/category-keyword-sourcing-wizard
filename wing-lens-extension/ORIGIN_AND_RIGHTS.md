# 독립 구현 및 권리 안내

이 확장 프로그램은 사용자가 제공한 기능 요구사항과 쿠팡윙 API 요청 규격을 바탕으로 새로 작성한 독립 구현물입니다.

## 포함하지 않은 것

- 셀로홈즈 또는 다른 분석 서비스의 소스코드
- 타 서비스의 로고, 아이콘, 이미지, 스타일시트 또는 폰트 파일
- 타 서비스의 고유한 화면 문구와 레이아웃
- 난독화된 웹 번들의 복호화 또는 재사용 코드

## 사용한 공개 인터페이스

- Chrome Extensions Manifest V3 API
- 사용자가 제공한 쿠팡윙 API 경로 및 요청 필드
- 일반 쿠팡 검색 결과 페이지의 상품 URL과 화면에 표시된 상품 정보

서비스명과 상표는 각 권리자에게 귀속됩니다. 이 프로젝트는 쿠팡 또는 셀로홈즈의 공식 제품이 아닙니다.

프로그램을 배포하거나 판매하기 전에는 쿠팡 이용약관, API 접근 권한, 개인정보 처리 여부 및 적용 법률을 별도로 확인해야 합니다. 이 문서는 법률 자문이 아닙니다.

## 저작권자 표기

배포 전에 아래 항목을 실제 권리관계에 맞게 작성하세요.

- 제작·운영자: `[이름 또는 상호]`
- 문의처: `[선택 입력]`
- 배포 조건: `[개인용 / 사내용 / 별도 라이선스]`
